## 2025-04-25 - Supabase Pagination Query Optimization
**Learning:** Supabase pagination queries can avoid N+1 issues and secondary count query overhead by using `count="exact"` within the primary `.select()` operation (e.g., `.select("*", count="exact")`). This combines the data fetch and total count retrieval into a single database request. However, when working with the Python client response, parsing the total correctly requires a robust fallback pattern: `total = result.count if hasattr(result, 'count') and result.count is not None else len(result.data)`.
**Action:** When implementing pagination with Supabase in Python, always utilize `count="exact"` in the primary `select` query to eliminate the need for a separate count query, improving database performance and reducing latency. Ensure the response parsing handles the count attribute safely.
