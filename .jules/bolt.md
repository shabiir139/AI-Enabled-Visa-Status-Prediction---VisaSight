## 2024-05-24 - Supabase N+1 Pagination Optimization
**Learning:** Supabase Python client's `.select()` method supports a `count="exact"` parameter that retrieves both the paginated data and the total row count in a single database round-trip. Previously, the pattern was to run `.select("*")` with ranges, and then a completely separate `.select("id", count="exact")` query, essentially halving the performance of list endpoints due to the N+1 query problem. PostgREST handles returning this count in the response headers alongside the data.
**Action:** When implementing pagination with the Supabase client, always append `count="exact"` to the primary query and parse the count from the response object (e.g., `result.count if hasattr(result, 'count') and result.count is not None else len(result.data)`) to eliminate redundant database queries.
