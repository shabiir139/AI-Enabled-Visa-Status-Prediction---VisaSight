## 2024-06-21 - Optimize Supabase Pagination Queries
**Learning:** For paginated endpoints like `list_visa_cases` and `list_visa_rules`, we can avoid an N+1 query problem by appending `count='exact'` to the primary `select('*')` query rather than executing a separate `.select('id', count='exact')` query. PostgREST handles the calculation of the total count based on applied filters correctly while applying range and limit modifiers to the returned data, effectively retrieving both the data and the total count in a single database round-trip.
**Action:** When implementing pagination with the Supabase client, always append `count='exact'` to the initial `select` query and extract the count from the `result.count` attribute instead of firing two separate queries. Use a fallback pattern like `result.count if hasattr(result, 'count') and result.count is not None else len(result.data)` to handle potentially missing count attributes robustly.
