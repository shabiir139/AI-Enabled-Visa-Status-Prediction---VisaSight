## 2024-05-24 - [Optimize Backend Pagination Queries & Event Loop Unblocking]
**Learning:** Combining Supabase `select` and `count` operations via `.select('*', count='exact')` effectively solves an N+1/1+1 bottleneck, halving the database roundtrips required per listing request. Additionally, synchronous API interactions (like `supabase.execute()`) executed within `async def` FastAPI route handlers block the main event loop, significantly degrading concurrent performance. Converting these endpoints to synchronous `def` offloads them to an external thread pool, enhancing the concurrency capability of the application without the overhead of asynchronous adapters.
**Action:** When creating or modifying backend pagination queries against Supabase, consolidate data retrieval and total counts using `count='exact'`. Evaluate all FastAPI route handlers containing synchronous operations to ensure they are defined with `def` rather than `async def` to avoid main thread blocking.
