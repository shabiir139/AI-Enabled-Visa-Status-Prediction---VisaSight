## 2026-10-24 - Supabase Pagination Optimization
**Learning:** Using separate queries for `.select("*")` and `.select("id", count="exact")` causes redundant database round-trips for pagination. PostgREST allows getting both the paginated records and the total filter-matched row count in a single request by appending `count='exact'` to the primary `select('*')` query (e.g., `supabase.table("table").select("*", count="exact")`). It correctly calculates the total count based on applied filters while ignoring range/limit modifiers.
**Action:** Always append `count='exact'` to the primary `select` query when implementing pagination in Supabase to eliminate the N+1 query problem, handling potential missing counts via `result.count if hasattr(result, 'count') and result.count is not None else len(result.data)`.
