## 2025-02-14 - Optimize Pagination with Supabase\n**Learning:** Supabase Python client supports retrieving exact row count along with paginated data in a single request by passing `count='exact'` to the `select` method. This avoids N+1 queries for pagination and keeps filter state consistent without duplicating query logic.\n**Action:** Use `select('*', count='exact')` when building paginated queries in Supabase and access the count via `result.count` instead of issuing a separate count query.
