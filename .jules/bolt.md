## 2024-05-18 - FastAPI Synchronous Database Client Thread Pooling Optimization
**Learning:** The Supabase Python client is synchronous and blocking. When used within `async def` FastAPI route handlers, it blocks the main event loop, significantly reducing concurrent request throughput. Additionally, running two separate queries to get data and the total count (N+1-like pattern) wastes an unnecessary database round-trip.
**Action:** Always declare FastAPI route handlers with `def` (instead of `async def`) when they contain synchronous CPU-bound or I/O-bound operations (like ML inference or synchronous Supabase clients). This instructs FastAPI to run the function in an external thread pool, keeping the main event loop free. Furthermore, for pagination queries, combine retrieving records and exact counts into a single `.select('*', count='exact')` query to halve the number of DB round-trips.
